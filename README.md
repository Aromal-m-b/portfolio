# Aromal MB — Portfolio

Personalized from LuckeyDuckey's MIT-licensed portfolio. Preserves the original charcoal and amber theme, 3D WebGL computer, and terminal. No personal photographs are used.

## Preview

Run `python -m http.server 8000` from this folder and visit http://localhost:8000.
No build step or package installation is required.

## Content

- `index.html`: biography, six projects, experience, education, contact links.
- `Scripts/TerminalFunction.js`: terminal biography and project shortcuts.
- `Styles/Main.css`: original styles plus responsive layout.
- `Aromal_MB_Resume.pdf`: downloadable AI/ML engineer resume.

The arrow switches between the portfolio and retro terminal. In the terminal, type `help`, `ls`, `start about.txt`, or `cd projects` followed by `ls`.
